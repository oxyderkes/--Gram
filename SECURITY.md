# Безопасность

Не публикуйте в Issues номера телефонов, коды входа, файлы сессий, журналы с персональными данными, API hash или ключи подписи.

При обнаружении случайно опубликованного секрета немедленно отзовите его у соответствующего провайдера. Удаление строки из последующего коммита не удаляет значение из истории Git.
