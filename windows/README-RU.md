# Исходный overlay ά‑Gram для Windows

Overlay версии `7.1.2-a-gram.15` предназначен для Telegram Desktop `v7.1.2`, коммит `3772337dd3e435b6269297f9db8f65959f8abe89`. Подмодуль `cmake` использован на коммите `ce47e85122cfa87d4ba4550049377f5167d31226`.

Архив содержит только изменённые файлы поверх официального дерева исходников, графические ресурсы, логотип и локальные вспомогательные сценарии. Ключи API, `local.properties`, CMake cache, зависимости, бинарные промежуточные файлы и журналы сборки не включены.

## Применение

1. Получите официальный репозиторий Telegram Desktop с подмодулями и переключитесь на указанный коммит.
2. Распакуйте каталог `overlay` в корень репозитория с заменой файлов.
3. Файл `overlay/cmake/run_cmake.py` относится к подмодулю `cmake`.
4. При необходимости адаптируйте пути к Visual Studio и локальному Python/Git в каталоге `build-helpers`.
5. Перед конфигурацией задайте свои `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` только через переменные окружения.
6. Соберите Qt Shader Tools 6.11.0 сценарием `build-qsb-6.11.0.cmd`, если в установленном Qt отсутствует `qsb.exe`.
7. Выполните `configure-agram-7.1.2.cmd` и `build-agram-7.1.2.cmd --clean-first`.

Проверенная конфигурация: Windows x64, Visual Studio Build Tools 2026, MSVC 14.44, Windows SDK 10.0.26100.0, CMake 4.3.1, Ninja, Qt 6.11, конфигурация Debug.

В этой версии overlay также находятся оптимизация инициализации множества аккаунтов, пакетная запись локальных архивов, метка `{DELETED}` рядом со временем, прозрачность сохранённых удалённых сообщений, локальная история редактирований, фоновая предзагрузка медиа и экспорт диалогов/сообщений выбранного автора в HTML + PDF. Секретные чаты интегрированы как отдельный тип элемента общего списка; добавлены создание, шифрованные сообщения и файлы, таймер, отпечаток ключа, локальная история и сохранение ручных удалений с исключением самоуничтожения. В `.12` самодельная секция переписки заменена адаптером к штатным `HistoryView::ChatWidget` и `History`, устранено падение при приведении `Dialogs::Entry` к истории, а отправка файлов, стикеров, удаление и локальный поиск перенаправлены в подсистему Secret Chats. В `.13` восстановление локальных секретных диалогов запускается только после полной инициализации компонентов `Main::Session`, что устраняет стартовое обращение к ещё не созданной подсистеме `EphemeralMessages`. В `.14` virtual-расширение удалено из базового `Dialogs::Entry`, а preview секретного диалога получается через явную проверку типа. В `.15` исправлен подтверждённый отладчиком use-after-free при завершении заблокированного аккаунта: записи Secret Chats удаляются до уничтожения зеркальных `History`. Оперативные снимки сообщений ограничены 5000 элементами и 32 МБ, архив удалений — 20 000 элементами, история правок — 10 000 версиями; удалённые сообщения восстанавливаются лениво для открытого диалога, до 2000 за раз. Перенос на Telegram Desktop 7.1.2 добавляет поддержку актуальных типов сообщений и сохраняет проверки границ языковых таблиц. В подмодуле CMake адаптированы локальные библиотеки zlib/minizip и обработка путей сборки.

Публиковать Telegram API ID/API hash, `local.properties`, CMake cache и журналы конфигурации не следует.
